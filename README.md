# 🎨 AURA AI Business Analytics — Frontend Suite

**AURA AI Business Analytics** is an enterprise-grade React 18 + TypeScript single-page application (SPA) featuring glassmorphism dark-mode aesthetics, collapsible 12-module navigation, real-time AI copilot streaming, and comprehensive governance controls.
